## COPSAC2010-gut-microbiota-maturation
R analysis code for longitudinal dynamics of gut microbiota maturation and its modulators from infancy through childhood

## Description
# Gut_maturation_code_Figure 1. Developmental trajectories of gut microbiota. 
This script analyzes age-related changes in microbial diversity, community composition, and beta-dispersion from infancy through childhood. It identifies developmental turning points and compares within-cohort maturation patterns with an external longitudinal cohort.

# Gut_maturation_code_Figure 2. Microbiota maturation and environmental associations. 
This script estimates microbiota age and microbiota-by-age z-scores using random forest models. It tracks transitions between maturity groups and examines associations between early-life environmental factors and microbiota maturation.

# Gut_maturation_code_Figure 3. Microbial characteristics of high- and low-maturity groups. 
This script compares microbial diversity, community composition, and beta-dispersion between maturity groups across ages. It also examines turnover, nestedness, and microbial association networks.

# Gut_maturation_code_Figure 4. Species-level patterns associated with microbiota maturation. 
This script identifies differentially abundant bacterial species between maturity groups across ages. It characterizes transient and persistent associations and visualizes the developmental trajectories of representative species.

# Gut_maturation_code_Figure 5. Prediction of microbiota maturity and functional characterization. 
This script predicts four-year microbiota maturity using one-year microbial profiles and evaluates predictive species and compositional balances. It also examines within-child community changes, microbial networks, and inferred metabolic functions of bacterial modules.

## Data access
Individual-level COPSAC2010 metadata are not included in this repository and require approved access.

## Usage
The scripts require the corresponding input datasets and R packages. Update local file paths before running the analyses.
